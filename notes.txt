implement the iris dataset inference using port-forward
create ns ml
kubectl create namespace ml


cat <<EOF | kubectl apply -n ml -f -
apiVersion: serving.kserve.io/v1beta1
kind: InferenceService
metadata:
  name: sklearn-iris
spec:
  predictor:
    model:
      modelFormat:
        name: sklearn
      storageUri: "gs://kfserving-examples/models/sklearn/1.0/model"
      resources:
        requests:
          cpu: "100m"
          memory: "512Mi"
        limits:
          cpu: "1"
          memory: "1Gi"
EOF

kubectl get all -n ml
kubectl get ing -n ml
kubectl -n ml port-forward svc/sklearn-iris-predictor 8080:80 --address 0.0.0.0


curl -s -H "Content-Type: application/json" -d '{"instances":[[5.9,3.0,5.1,1.8]]}' http://localhost:8080/v1/models/sklearn-iris:predict

this curl will return the prediction as {"predictions":[2]}

Intent-classifier serving

to enable kserve, we need to have storageuri it can be s3, gcs, azure blob storage, http/https (https://raw.git...), pvc, hugging face hub, OCI image (model cars), Modelkits, git, we are using git for dev activity git releases create release, tag and upload the intent_model.pkl generated by train.py in our intent model classifier and copy the link address and use in storageUri of the InferenceService

cat <<EOF | kubectl apply -n intent -f -
apiVersion: serving.kserve.io/v1beta1
kind: InferenceService
metadata:
  name: intent-classifier
spec:
  predictor:
    model:
      modelFormat:
        name: sklearn
      storageUri: "https://github.com/tvkrishna21/Intent-classifier-model/releases/download/intent-classifier/intent_model.pkl"
      resources:
        requests:
          cpu: "100m"
          memory: "512Mi"
        limits:
          cpu: "1"
          memory: "1Gi"
EOF
