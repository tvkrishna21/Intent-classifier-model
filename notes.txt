For ingress we need to have a domain registered, as it is dev activity we will use it with work around solution

curl -X POST --resolve <domain name used in ingress>:80:<ingress load balancer ip> http://<application endpoint> -H "Content-Type: application/json" -d '{"input to model"}'

We get the ingress load balancer as below, getent is similar to dig, nslookup...
~ $ kubectl get ingress -n intent-namespace

curl -X POST --resolve vamshi.com:80:54.152.233.219 http://vamshi.com/predict -H "Content-Type: application/json" -d '{"text":"I want to cancel my subscription"}'
this will return {"intent":"complaint"}


curl -X POST --resolve vamshi.com:80:54.152.233.219 http://vamshi.com/predict -H "Content-Type: application/json" -d '{"text":"Howz u"}'
this will return {"intent":"greeting"}
